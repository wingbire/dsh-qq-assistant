### Our Free Model 实测可用模型

在 headless 下逐个试过（`provider: our-free-model`）：

| 模型 | 大脑 | 二判 | 备注 |
|---|---|---|---|
| `nvidia/nemotron-3-ultra-550b-a55b:free` | ✅ 约 **7.8s** 出稿，内容可用 | ✅ **3/3 判对**，约 13s | **推荐默认** |
| `kilo-auto/free` | ✅ 约 13s 出稿 | ⚠️ 8s 超时下全超时 | 慢一些 |
| `ling-3.1-flash-free` 等 `*-free` | ❌ OpenCode 车道，指纹拒绝 | ❌ 同 | 不可用 |
| `deepseek-ai/deepseek-v4.1-flash` 等 sealIds | ❌ 空文本 | ❌ | 那条车道要登录 |

**代价**：免费池**不享前缀缓存**（实测 `cacheReadTokens: 0`），而官方模型命中率 94~96%。
所以「省下来的钱」和「慢 + 没缓存」要自己权衡。走 OFM 时外审超时记得放宽到 20000（20 秒），否则会一直判「不确定」。
| **语音依赖 Windows SAPI** | 只有 Windows 能合成 | 非 Windows 可关掉语音，其余功能不受影响 |
| **识图默认关闭** | 打开后默认与大头脑同一个模型（`同大脑`，实测 6.9 秒出描述）；也可切 `http` 自配接口 | 默认关，开了就能用 |
| **不做语音转写** | 群里发的语音听不到内容（人设里写死【听不到语音】） | 想让它真听懂需要一个 STT 后端，尚未接 |
| **只支持 OneBot v11** | NapCat / go-cqhttp 等 | 够用，但要接别的协议得写适配 |
| **配置端无鉴权** | 只听 `127.0.0.1`，但没有登录 | 设计如此（本机工具）；**别**把它暴露到公网 |

### 效果上

| 限制 | 说明 |
|---|---|
| **新群前 80 条不说话** | 这是设计，不是 bug。想立刻看效果改 `stageMode = live` |
| **自学习需要时间** | 阈值自适应、群档案重炼都靠真实反馈积累，前几十轮效果一般 |
| **本地判定会误判** | 保守方向（宁可少说）是刻意选的；嫌它太闷就调低开口阈值 |
| **≥3 个模型档位的差异** | 三档只改 reasoning effort 与字数上限，不改人设 —— 这是为了缓存 |

## N22 搜索闸门 + 引用回复（2026-10-14）

- **问题**：实测 126 条判定里 **58 条要搜**（「无敌了」「我去调调」都去搜了），一次搜索约 5 秒还拖慢回复；
  人设里**完全没教它用 [引用]**，所以几乎不会引用回复。
- **改**：搜索要「真有信息需求（提问/求详 + 会变的信息或链接，或用户说搜一下）」且
  「检索词像话（去废词/纯数字/全废词拼词）」；低档永不搜；中档默认 search: 0（默认值同步改了）。
  人设新增【引用回复】块（开关关掉就不写）；sent 观测新增 reply:{used,wanted,mode,auto} 便于核对。
- **验证**：单测全过；带标签情景回归 13/16 不变（另 3 条「不回」本就该不回）。

## 话题词条生命周期（2026-10-14）

- **问题**：群档案兴趣词条是「并集 + slice」，只会加不会删 —— 实测攒下「是什么 / 给小 / 看史」这类碎片，长期话题进不来。
- **改**：每个词带证据（命中次数 / 跨天 / 首末时间），分「观察区 → 固化 → 沉寂降级」三段；临时的 3 天清掉，稳定（≥4 次且跨 ≥2 天）才固化，固化后 21 天没提先降级；管理员手写的钉住。提示词只放固化的词（保前缀缓存）。
- **验证**：单测覆盖 临时过期 / 跨天固化 / 沉寂降级 / 手写钉住 / 旧档案迁移（并修掉迁移时把 lastAt 刷成当下、导致沉寂天数永远算不出来的 bug）。

## N24 引用回复改成「按是否明确指向」（2026-10-15）

- **现象**：49 条回复里 0 条引用 —— 原来只有「对方用引用发来」或「模型主动写 [引用]」才触发，@ 她这种最典型的指向反而没引用。
- **改**：只问「这条是不是在明确回某个人/某一条」：被 @ / 对方用引用发来 / 模型写 [引用] → 引用；自己陈述、闲聊、讨论、主动搭话 → 直接发言不引用。跟回答长短无关（去掉原来的「高档不引用」）。
- 人设里把「什么时候用 / 什么时候别用」写成两条明确规则；sent 观测与后台消息表都标 quote:true。
- **方向纠正（用户澄清）**：不是「别人 @ 她」就引用 —— 是**她自己的发言指向别人的某条消息**时才引用；@ 她直接答就行。
- **验证**：新增测试覆盖 @她→引用、闲聊→不引用、对方引用→引用回去、关→从不、仅标记→只听模型；单测 225 → 226。
