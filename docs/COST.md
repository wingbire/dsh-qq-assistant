# 成本实测（每条回复花多少钱）

> 本文件由 **`node demo/cost-report.mjs --no-measure --doc`** 依据实测样本自动生成 —— 想复核或换价目表，改 `demo/cost-report.mjs` 里的 `PRICE` 再跑一遍。
> 样本落盘在 `app/dsh-data/_probe/cost-samples.json`（本地，不进仓库）。

## 0. 一句话结论

- **本地短答（低档）完全不花钱**：0 token，实测日志里 4 条 low 档回复用量全是 0。
- **一条普通中档回复 ≈ 0.0018 元**（中位数），**均值 0.0034 元**；1000 条约 1.81 元。
- **外审（二判）≈ 0.0015 元/次**；**识图 ≈ 0.0018 元/次**。
- **冷启动贵 4 倍**：刚改完人设 / 刚重启的那一次是缓存未命中（6,530 输入 tokens → 0.0073 元），之后每轮只花 0.0018 元。
- **长尾才是风险**：高档档位里 agent 自己多步探索的那次，prompt 冲到 **72,194 tokens**，单条 **0.0231 元** —— 是普通回复的十几倍。

模型：**`deepseek-flash`（服务版本 DeepSeek-V4.1-Flash）**，官方页注明**支持图像理解**（所以识图默认走它）。

| 项 | 空闲时段 | 高峰时段 |

| 输入（缓存命中） | 0.02 元 | 0.04 元 |
| 输入（缓存未命中） | 1 元 | 2 元 |

*空闲时段半价；高峰 = 北京时间周一至周五 9:00-12:00 / 14:00-18:00（法定节假日除外）。下表金额一律按**空闲时段**算（高峰翻倍）。*

## 3. 一次「回复」的成本构成

| 组合 | 成本中位数(元) | 说明 |
|---|---|---|
| 低档：一个字都没发/本地短答 | 0 | 判定为 no 或走本地短句池，**不调模型** |
| 中档回复 | 0.0018 | 1 次大脑调用（人设 + 上下文 ≈ 6.9k prompt，九成命中缓存） |
| 中档 + 外审 | 0.0033 | 被点名 / 求详 / 没点名但要进大脑时多一次 |
| 高档回复（正常一次） | 0.0027 | 同上；**多步探索那种长尾 0.0231 元**，见 §5 |
| 带图回复 | 0.0036 | 多一次识图（图片 tokens 进 prompt，约 13k） |

**prompt 里最贵的是什么**：人设前缀（约 6.4k tokens）几乎每轮都命中缓存（0.02 元/百万，是未命中的 1/50），
所以「一个人设只改尾巴」这件事直接决定账单 —— 实测**稳态缓存命中率 92.6%**（刚改人设 / 刚重启那一次是冷启动，63.6%）。

## 4. 阈值建议（怎么设预算）

程序里的日预算 `runtime.budget.dailyTokens` 单位是 **tokens**（默认 5,000,000），换算：

| 目标 | 折算 tokens | 折算金额(元/天) |
|---|---|---|
| 每天 100 条普通回复 | 711,400 | 0.18 |
| 每天 300 条普通回复 | 2,134,200 | 0.54 |
| 每天 1000 条普通回复 | 7,114,000 | 1.81 |
| 极端：每天 50 条「多步探索」的高档回复 | 3,742,900 | 1.16 |

建议：**默认 500 万 tokens 太宽松**（够 700 条/天，约 1 元）。想让它真的「熔断」，按你每天愿意花的条数倒推设：
比如「每天最多 200 条普通回复」 → `dailyTokens ≈ 1,422,800`。

## 5. 两个必须知道的坑

1. **高档档位的长尾来自 agent 多步探索，不是字数上限**。实测同档两次：一次 6,914 prompt / 6.3 秒 / 0.0129 元，
   另一次 **72,194 prompt（60,928 命中缓存）/ 32 秒 / 0.0231 元** —— 模型在 profile 里有工具，会自己读写文件、跑命令，步数一多 prompt 就滚起来。
   控制手段：日预算熔断、`runtime.budget.groupHourlyLimit`、以及把 high 档留给真正需要长答的场景。
2. **三档的 `reasoningEffort` 目前没生效**：`ensureBrainProfile` 写了 `tier-low/mid/high.patch.yml`，
   但 `askBrain` 调 `runBrain` 时没带 `--patch` —— 也就是现在**三档只有提示词里的字数上限不同，模型与思考模式不变**。
   这对账单其实是好事（high 档没有额外的思考 token），但如果你想要「详细档真的多思考」，就得把 tier patch 接上，代价是输出 token 明显变多。

> 配置端**状态页**也显示这几个数：今日花费 / 平均每条回复 / 缓存命中率（含命中省下）/ 本地判断省下，
> 外加日预算滑块与各群花费 —— 都在同一张「成本（今日）」卡片里，卡片可折叠。
