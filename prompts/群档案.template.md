# 群档案 Prompt 模板（每群一份，由大脑每 20 次回复重炼）

这一段是"输出内容的提示词前缀"，在全局人设之后、本轮任务之前注入。

---

【本群画像 · 群号 {gid}】

- 常聊且容易接话的话题：{interests}
- 容易冷场或反感的话题（少碰）：{dislikes}
- 群友说话习惯：{habits}
- 活跃时段：{activeHours}
- 本群节奏：{pace}
- 其他注意：{notes}

【本群行为参数】（由 profile.js 的 PARAM_BOUNDS 约束，越界会被夹回）

- 开口阈值 speakAt = {speakAt}
- 常规线 terseAt = {terseAt}
- 多讲线 detailedAt = {detailedAt}
- 成本权重 lambda = {lambda}
- 主动参与意愿 rate = {rate}

---

## 生成方式（refitProfile 的输入与输出）

输入：该群最近 20 次回复的互动记录 {outcome, tokens, arm, bucket, 时间}
输出：{ interests, dislikes, habits, notes, pace, updatedAt, rounds }
用途：① 作为 prompt 前缀注入 ② 关键词表喂给 classify 的话题深度 ③ 越界参数经 clampParams 夹回
